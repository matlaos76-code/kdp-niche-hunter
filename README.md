# KDP Niche Hunter v4 - Analizator Nisz Amazon KDP + Eksport KDP

Live demo po wrzuceniu na GitHub Pages.

## Funkcje
- Wyszukiwarka z przyciskiem SZUKAJ -> raport TYLKO dla wybranej niszy, generuje nowe nisze live
- Przycisk Aktualizuj dane na dziś (przelicza BSR, sprzedaż)
- Generator: 3 tytuły Amazon-compliant, 7 Kindle Keywords, 3 kategorie, opis A+
- Eksport: CSV + TXT gotowy do wklejenia w KDP + kopiuj wszystko
- Kalkulator zysków, Q4 Radar, checklist walidacji

## Deploy na GitHub Pages - 30 sekund bez terminala
1. Stwórz repo `kdp-niche-hunter` na github.com
2. Upload files -> przeciągnij `index.html` z tego folderu
3. Settings > Pages > Deploy from branch: main / root
4. Gotowe: https://TWOJ_LOGIN.github.io/kdp-niche-hunter/

Plik to single-file React + Tailwind via CDN, działa offline.

## Jak używać eksportu KDP
1. Wpisz niszę np. `anxiety journal` -> Szukaj
2. Kliknij Wygeneruj 3 tytuły
3. Kliknij Pobierz plik KDP (TXT) - dostajesz gotowy listing do wklejenia w panel KDP
4. Lub Eksportuj CSV do Excela
